THE CHALLENGE

A useful collection can still leave someone wondering how to apply it. Finding a term was only the first step.

MY CONTRIBUTION

I organized the reference material around practical tasks, then connected framework guidance to a prompt worksheet.

01Reference to use02Build the brief03Inspect the output+Where it landed

01 / Before and current

The collection needed a next step.

The earlier glossary put search, filters, and definitions in one dense view. CLARE separates the jobs: find a term, choose a framework, or check a prompt. The reference is still there, with more room to understand what to do next.

02 / Working example

Turn the framework into a working brief.

The COSTAR worksheet asks for context, objective, style, tone, audience, and response format. Those fields give an abstract framework a practical use. This demonstration builds an invitation brief for a fictional library workshop.

03 / Output and control

Keep the ingredients visible.

CLARE assembles the inputs and source-framework checks into a copyable worksheet. The person can inspect it, revise the inputs, and rebuild before using an AI assistant. The worksheet stays in the browser.

WHERE IT LANDED

A public workspace with a usable path through the reference.

The glossary, framework library, and browser-local worksheet now connect research material to a concrete prompt-building task. The next evaluation is whether beginners can choose and adapt a framework without help.

What I learned and would test next

The interface has to teach the next action. A larger catalog alone does not establish usefulness.

I would observe first-time users choosing a framework, filling the worksheet, and deciding what to change before sending it to an AI tool.

Evidence: preserved 2025 site, current CLARE source, and a fresh live worksheet interaction. Catalog status labels are inherited; this case does not claim every entry was freshly verified.
