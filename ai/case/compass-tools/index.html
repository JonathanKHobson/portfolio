THE CHALLENGE

Open-ended AI feedback is hard to act on when observation, interpretation, and suggested changes are mixed together.

MY CONTRIBUTION

I turned recurring review tasks into focused tool workflows with structured inputs, inspectable outputs, and clear limits.

01 / Tool family

Start with the decision someone needs to make.

The tools share a principle, not a single catch-all prompt. Each asks for different evidence and produces a different kind of help. MCP connections let an AI assistant call these focused tools within a larger workflow.

02 / Actual output

Make a finding something a team can inspect.

UX Heuristics Compass separates the observation, evidence, severity, and next action. The report gives a designer or teammate a specific finding to discuss. A score summarizes the supplied review; it does not replace testing with people.

03 / Workflow

The person owns the next step.

A tool can organize what to inspect. I design the handoff so a person can question the evidence, revise the interpretation, or ask for a better source before acting.

Shared pattern across distinct tools

  1. 01

    Supply

    A task, draft, or interface evidence.

  2. 02

    Structure

    A focused tool organizes the review.

  3. 03

    Inspect

    A person checks the finding and its limits.

  4. 04

    Act

    Revise, investigate, or keep the decision.

WHERE IT LANDED

Working tools with inspectable outputs.

The public betas include examples, setup guidance, and source packages. The private tools remain separate. Together they demonstrate how I turn expert review habits into workflows an AI assistant can support.

What I learned and would test next

More tools are useful only when the boundaries are clear. A claim checker, a prompt reviewer, and a usability audit should not pretend to certify the same thing.

I would test whether a new user can choose the right tool and understand when to challenge its output.

Evidence: original tool READMEs, public release pages, and the archived UX Heuristics Compass report. No adoption or measured productivity gain is claimed.
